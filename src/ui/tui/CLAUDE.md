# The Elm Architecture for Terminal User Interfaces

This module implements The Elm Architecture (TEA) pattern for building maintainable, testable terminal user interfaces.

For comprehensive guidance on Elm Architecture patterns, best practices, anti-patterns, finite state machines, and ECS integration, use the **elm-design skill**:

```bash
/skill elm-design
```

The skill includes:
- Core architecture reference with Rust examples
- Nested component composition patterns
- Common anti-patterns and how to fix them
- Finite state machine design patterns
- Integration patterns with ECS systems
- Scripts for analyzing code and generating diagrams

See `.claude/skills/elm-design/SKILL.md` for complete documentation and workflows.
