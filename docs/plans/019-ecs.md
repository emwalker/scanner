## Proposal 1: Change Detection Pattern

Add dirty tracking to UI model components to avoid redundant re-renders when data hasn't changed.

### Tasks
- [ ] Add `dirty: bool` and `last_rendered: Instant` fields to `WindowProgress`
- [ ] Add `dirty: bool` field to `CandidateProgress`
- [ ] Mark components dirty in update methods when state actually changes
- [ ] Check dirty flags in render logic before expensive operations
- [ ] Reset dirty flags after rendering
- [ ] Run `make lint` and `make test`
